Ajouter un document

Interface préparée pour envoyer un fichier vers une destination contrôlée. L'upload réel nécessite un backend sécurisé ; aucun token GitHub ni mot de passe n'est stocké dans cette page.

🔐 Règles prévues côté serveur

  • Mot de passe vérifié côté serveur uniquement.
  • 10 Mo maximum par fichier.
  • 10 fichiers maximum par identifiant utilisateur et par jour.
  • Extensions autorisées contrôlées côté serveur.
  • Chemin de destination limité à une liste blanche.
  • Token GitHub conservé exclusivement comme secret du backend.

🌐 IP et quota

L'adresse IP peut être utilisée temporairement pour la protection anti-abus, mais elle ne doit pas être enregistrée en clair dans le dépôt. La solution recommandée est un identifiant de quota calculé côté serveur, idéalement combiné à un utilisateur/session plutôt qu'à l'IP seule.

Une protection JavaScript seule n'est pas une sécurité : le code et tout secret intégré seraient visibles par n'importe quel visiteur.
