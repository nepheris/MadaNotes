Ajouter un document

Interface expérimentale. Le formulaire montre le fonctionnement prévu, mais l’envoi réel reste désactivé tant qu’un backend sécurisé n’est pas configuré.

Important : aucun mot de passe ni token GitHub n’est stocké dans cette page. La future validation du mot de passe, les quotas et l’écriture GitHub devront être réalisés côté serveur.

🔐 Règles prévues

  • Mot de passe vérifié uniquement côté serveur.
  • 10 Mo maximum par fichier.
  • Quota utilisateur public : cible de 10 fichiers par jour.
  • Liste blanche des dossiers et extensions.
  • Token GitHub gardé uniquement comme secret du backend.
  • Les push GitHub réalisés directement par le propriétaire ne sont pas concernés par ce quota applicatif.

🧪 État expérimental

Cette page ne doit pas être considérée comme un service d’upload actif. Elle sert à valider l’UX avant branchement du backend.
